# 🎬 Movieflix - Movie Discovery & Watchlist Web App

Movieflix is a responsive, dark-themed web application that allows users to search for movies, view ratings and plot details, and manage a personal watchlist stored directly in their browser.


---

## ✨ Features

- **🔍 Live Movie Search**: Search thousands of titles using the OMDb API to fetch live poster artwork, IMDb ratings, runtime, genre tags, and plot summaries.
- **📌 Personal Watchlist**: Add movies to your watchlist with a single click.
- **💾 Persistent Storage**: Watchlist items are saved in `localStorage`, so your saved movies persist across page reloads and browser sessions.
- **📱 Fully Responsive**: Custom CSS media queries ensure a seamless experience on desktop, tablet, and mobile devices.
- **🌙 Modern Dark Mode**: Styled with modern CSS custom variables, soft glassmorphism accents, and high-contrast typography.

---

## 🛠️ Built With

- **HTML5**: Semantic markup for structured, accessible pages.
- **CSS3**: Custom CSS variables, Flexbox, media queries, and dark-theme UI.
- **JavaScript (ES6+)**: Fetch API, async data rendering, dynamic DOM manipulation, and `localStorage`.
- **OMDb API**: External REST API used to retrieve live movie data.

---

## 🚀 Getting Started

### Prerequisites
You need a web browser and an OMDb API Key (you can request a free API key at [omdbapi.com](https://www.omdbapi.com/apikey.aspx)).
